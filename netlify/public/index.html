API de pagamentos — Gás do Povo

Este é o backend da Cakto (PIX). O site em si fica no GitHub Pages.

  • POST /api/vizzionpay/pix — gera a cobrança PIX
  • GET /api/vizzionpay/status?identifier= — confirma o pagamento
  • GET /api/vizzionpay/fees — taxas cobradas do comprador
  • POST /api/vizzionpay/callback — notificação do gateway
